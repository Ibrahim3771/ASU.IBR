# كوفي درر

تصميم داخلي فاخر لمحل كوفي بمساحة **3.80 × 10.86 م**، مع بار وجلسات كنب وطاولات وحمّام وشعار ثلاثي الأبعاد باسم **درر**.

## الملفات

- `index.html` — عرض التصميم الكامل (الهوية، المخطط، المناطق، الخامات)
- `tour.html` — جولة ثلاثية الأبعاد تفاعلية بالمقاسات الحقيقية

- `design2.html` — التصميم الثاني (زمرد/ذهب) وبار يدخل منه الموظف للتحضير

افتح `index.html` عبر خادم محلي ثم انتقل إلى الجولة 3D أو التصميم الثاني.
